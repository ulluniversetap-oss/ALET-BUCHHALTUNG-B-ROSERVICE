# ALET Buchhaltung & Büroservice

Landingpage für Finanzbuchhaltung, Lohnabrechnung und Büroservice in Berlin.

Statische Seite ohne Build-Schritt: `index.html` + `styles.css`. Lokal einfach `index.html` im Browser öffnen.

Vor der Veröffentlichung Telefonnummer und E-Mail in `index.html` (Abschnitt `#kontakt`) eintragen.
